CSS text-shadow Complete Notes

1. inherit

inherit takes the value from the parent element. 

.parent {
  text-shadow: 2px 2px 4px blue;
}

.child {
  text-shadow: inherit;
}
Parent Text

Child Text using inherit

2. initial

initial sets the property to its default value. 

h1 {
  text-shadow: initial;
}

This text has no shadow

3. revert

revert reverts the property to browser/default stylesheet value. 

.special {
  text-shadow: revert;
}

Reverted Text Shadow

4. revert-layer

revert-layer reverts the property to the previous CSS layer. 

@layer base {
  h1 {
    text-shadow: 2px 2px 4px blue;
  }
}

@layer theme {
  h1 {
    text-shadow: revert-layer;
  }
}

Used mainly with modern CSS layers.

5. unset

unset acts like inherit for inherited properties. 

.parent {
  text-shadow: 2px 2px 4px green;
}

.child {
  text-shadow: unset;
}
Parent Text

Child Text using unset

6. Different text-shadow Syntax Examples

1. offset-x | offset-y | blur-radius | color

text-shadow: 1px 1px 2px black;

Black Shadow Example

2. color | offset-x | offset-y | blur-radius

text-shadow: #ffcc00 1px 0 10px;

Yellow Glow Shadow

3. offset-x | offset-y | color

text-shadow: 5px 5px #558abb;

Blue Shadow Example

4. color | offset-x | offset-y

text-shadow: white 2px 5px;

White Shadow Example

5. offset-x | offset-y

Uses default color and blur-radius. 

text-shadow: 5px 10px;

Default Shadow Example

Value Meaning
inherit Takes value from parent
initial Sets default value (none)
revert Reverts to browser/default style
revert-layer Reverts to previous CSS layer
unset Acts like inherit for text-shadow
